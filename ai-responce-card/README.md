# AI Response Card

## Overview

The AI Response Card is a reusable component for presenting AI-generated information with user interaction controls.

## Features

* AI response display
* AI identity indicator
* Copy response
* Regenerate response
* Positive feedback
* Negative feedback
* Feedback message
* Responsive design

## Technologies

* HTML5
* CSS3
* JavaScript

## Files

```text
ai-response-card/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

Open `index.html` in a modern browser.

## Interaction

Users can:

* Read the AI-generated response.
* Copy the response.
* Regenerate the response.
* Provide positive feedback.
* Provide negative feedback.

## Design Pattern

Response cards are useful for presenting AI-generated information in a structured and reusable format.

They can be used in:

* AI search
* AI assistants
* Recommendation systems
* Analytics applications
* Content generation tools

## Originality

This is an original implementation created for the hackathon using common AI interface design principles.
